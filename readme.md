# 주가 조건 알림 봇

관심 종목의 일별 주가 데이터를 조회하고, 조회 가격이 설정한 기준 이상이면 디스코드 채널로 알림을 보내는 Python 프로젝트입니다.

## 제작 목적

Python 조건문을 실제 데이터 조회와 외부 API 호출에 연결하고, 발송 기록을 저장하여 중복 알림을 방지하는 과정을 학습했습니다.

## 주요 기능

- FinanceDataReader로 종목별 일별 가격 데이터 조회
- 마지막 데이터 행의 날짜와 Close 값 추출
- 설정 가격 이상일 때 디스코드 웹훅으로 알림 전송
- 종목 코드, 설정 가격, 데이터 날짜를 조합한 발송 기록 저장
- 동일한 기록이 존재하면 재전송 생략

## 동작 흐름

주가 조회 → 조건 판단 → 기존 발송 기록 확인 → 디스코드 전송 → 성공 후 기록 저장

## 확인한 동작

| 상황 | 결과 |
|---|---|
| 조회 가격이 기준보다 낮음 | 조건 미충족, 전송하지 않음 |
| 조회 가격이 기준과 같거나 높음 | 조건 충족, 알림 전송 |
| 같은 조건과 날짜로 재실행 | 기존 기록 확인, 전송하지 않음 |

## 개발 중 해결한 문제

- 현재 터미널 폴더와 파일 위치가 달라 실행 파일을 찾지 못했습니다. 프로젝트 폴더로 이동하여 해결했습니다.
- 웹훅 주소를 설정하지 않은 실행 환경에서 오류가 발생했습니다. 환경 변수를 설정한 터미널에서 실행하여 해결했습니다.
- 요청의 params를 딕셔너리 대신 집합으로 작성했습니다. 오류 메시지를 확인하고 이름과 값을 연결하는 딕셔너리로 수정했습니다.

## 현재 범위

수동으로 실행하는 프로그램입니다. 장중의 당일 Close 값은 최종 종가로 확정되기 전일 수 있습니다. 자동 실행과 조회·전송 실패에 대한 오류 처리는 이후 추가할 예정입니다.

## 설치 및 실행 방법

아래 명령은 Windows PowerShell 기준입니다. 먼저 터미널에서 프로젝트 폴더로 이동합니다.

### 1. 프로젝트 전용 파이썬 환경 만들기

```powershell
python -m venv .venv
```

### 2. 필요한 라이브러리 설치하기

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 3. 디스코드 웹훅 주소 설정하기

디스코드 서버 설정의 연동 메뉴에서 웹훅을 만들고, 메시지를 받을 채널을 선택합니다. 웹훅 URL을 복사한 뒤 아래 명령의 입력란에 붙여 넣습니다.

```powershell
$env:DISCORD_WEBHOOK_URL = Read-Host "웹훅 URL을 붙여 넣고 Enter"
```

웹훅 URL은 공개하지 않습니다. 이 설정은 현재 터미널에서만 유지되므로 새 터미널에서는 다시 설정해야 합니다.

### 4. 관심 종목과 기준 가격 설정하기

`price_alert.py`의 다음 변수를 수정하고 저장합니다.

```python
stock_name = "삼성전자"
stock_code = "005930"
target_price = 240000
```

기준 가격은 동작을 설명하기 위한 예시이며, 투자 추천 가격이 아닙니다.

### 5. 실행하기

웹훅 주소를 설정한 같은 터미널에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe price_alert.py
```

조건을 충족하면 디스코드로 알림을 전송하고 `sent_alerts.txt`에 발송 기록을 저장합니다. 같은 종목·기준 가격·데이터 날짜의 기록이 있으면 재전송하지 않습니다.

## 오류 처리

- 웹훅 환경 변수 누락: 설정 방법을 안내하고 종료
- 주가 조회 중 요청 통신 오류: 연결 확인을 안내하고 종료
- 빈 주가 데이터: 종목 코드와 조회 날짜 확인을 안내하고 종료
- 디스코드 오류 응답 또는 요청 통신 오류: 안내 후 종료
- 전송 단계에서 오류가 발생한 경우: 발송 기록을 추가하지 않음

테스트용으로 발생시킨 디스코드 통신 오류와 이후 재시도 성공을 확인했습니다. 모든 외부 서비스 오류 상황을 검증한 것은 아닙니다.
